SpendWise – Personal Finance Management App

SpendWise is a full-stack personal finance management application designed to help users track their income, expenses, budgets, and savings goals in one place.

Features

- User Registration and Login
- Personal Finance Dashboard
- Income and Expense Tracking
- Monthly Budget Management
- Savings Goals Tracking
- Financial Analytics
- Transaction History

Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Python, Flask
- Database: SQLite

How to Run Locally

1. Clone this repository.
2. Install the required dependencies:

pip install -r requirements.txt

3. Open the backend folder.
4. Run the application:

py app.py

5. Open your browser and visit:

http://127.0.0.1:5001

Project Purpose

SpendWise aims to make personal finance management simple and accessible by helping users monitor their spending habits and savings goals.
